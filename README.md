# agentbook

**Discontinued.** Superseded by [the Relay Principle](https://relayprinciple.ai).

agentbook coordinated AI work the way an org chart does: a coordinator agent
above workers, scouts and reviewers, with a SQLite ledger to keep them in sync.
It worked, but the machinery cost more than the problem it solved.

Relay does the same work with none of it — a chain of independent sessions,
each running one leg, handing off through three plain files on disk.
No coordinator. No subagents. No database.

Finish lines, not managers. The simpler thing won.
